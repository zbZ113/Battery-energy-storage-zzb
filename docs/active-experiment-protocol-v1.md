# 主动试验推荐协议 v1

## 目的与边界

`quanxin_life.experiments.gp_active` 是面向低维储能电芯工况的数值服务。它用于基于**已经观测并经过来源审核**的试验数据，拟合高斯过程、量化候选工况的不确定性，并给出受约束的试验排序。

它不读取 Naumann 原始文件，不构造任何 Naumann 数值，不加载序列化模型，也不通过 LLM 生成退化率、方差或推荐分数。数据接入与来源验证必须先由数据层完成；Agent 后续只能调用受治理的工具封装本模块。

## 输入契约

每个已完成试验必须显式提供：

- `temperature_c`；
- `mean_soc`；
- `dod`；
- `charge_c_rate`；
- `discharge_c_rate`；
- 一个有明确名称且真实观测到的目标，例如 `capacity_loss_rate`、`equivalent_cycle_degradation_rate` 或 `resistance_growth_rate`；
- 试验时长和设备成本。

缺失、非有限、混合目标名、重复试验标识或越出已审核工况边界的观测会被拒绝。模块不会插补，也不会把越界条件裁剪到边界。

调用者还必须提供经过人工审核的温度、平均 SOC、DOD、充放电倍率边界，以及时间和设备成本的归一化基准。边界不是电化学安全结论；它们只是当前设备与安全审批已经允许的候选空间。

## 模型与排序

特征顺序固定为：

```text
temperature_c, mean_soc, dod, charge_c_rate, discharge_c_rate
```

模型使用 `StandardScaler` 后的 scikit-learn `GaussianProcessRegressor`，内核固定为：

```text
Matérn(ν=2.5) + WhiteKernel
```

随机种子固定为 `20260712`。首版协议固定核参数并关闭隐式超参数优化：小样本工况数据常将噪声项推到边界，单次优化得到的数值并不能自动成为可靠结论。后续若引入核参数选择，必须将候选范围、选择集和结果一并版本化。模型只驻留内存；不得通过 pickle、joblib、`.pt` 或 `.pth` 读写。

对通过安全与设备检查的候选试验，排序分数为：

```text
预测标准差 / (时长 / 时长归一化基准 + 设备成本 / 成本归一化基准)
- 重复试验惩罚
```

重复惩罚由候选工况与既有观测工况在审核边界归一化空间中的最近相似度决定。完全相同的历史工况会得到完整惩罚；远离既有工况的候选仍可能有部分相似惩罚。该分数是信息不足与资源代价之间的启发式排序，不能表述为工业最优策略或安全批准。

以下候选不会预测、不会评分，也不会被静默修改：

- 任何工况字段越出边界；
- 未获得安全审批；
- 当前设备不可用。

它们会以明确拒绝码和约束细节返回。

## 回放评估

留一回放对每个已观测试验执行以下过程：

1. 排除该观测；
2. 用剩余观测重新拟合同一 GP；
3. 对被排除工况输出预测均值、标准差、真实观测值和绝对误差；
4. 汇总 MAE 与 RMSE。

回放报告仅包含实际比较量，不宣称 GP 或主动试验策略优于随机、网格或任何其他基线。策略优劣必须在固定候选空间、成本模型和逐轮数据揭示协议下，由独立实验脚本另行报告。

## 集成要求

后续 `recommend_next_experiment` 工具需要将输入来源、模型版本、边界版本、成本配置版本、输入哈希、数值输出及拒绝原因封装为 `ToolResult`。正式报告只能引用该受审计工具的 `result_id`，不能直接引用本模块的内存对象。
