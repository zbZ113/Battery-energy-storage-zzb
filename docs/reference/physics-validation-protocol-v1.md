# 短时物理工况核验协议 v1

## 目的与边界

本模块通过可选安装的 PyBaMM 对限定工况执行短时 SPMe 仿真，用于核验
电压、电流、放电容量和 SOC 响应，以及识别求解终止与边界风险。它不是
寿命或退化外推模块；任何此类结论必须由独立的数据驱动模型及其工具结果
给出。

## 固定配置

- 模型：`pybamm.lithium_ion.SPMe`。
- 参数集：`Prada2013`。
- 协议：由初始 SOC、SOC 窗口、充放电倍率和有限重复次数构造恒流
  `pybamm.Experiment` 步骤。
- 温度：将请求的摄氏温度显式写入环境与初始温度参数。
- 初始状态：`Simulation.solve(initial_soc=...)`。

SOC 窗口在本版本中被转换为“窗口跨度 ÷ C 倍率”的短时恒流时长。该换算仅
用于构造可审计的试验步骤，不等同于对目标电芯的标定，也不构成实际运行边界。

## 输入校验与降级

请求拒绝非有限值、越界 SOC、越界温度、非正倍率和超过三次的重复次数；
不会对任何输入静默截断或填补。PyBaMM 未安装时，或外部求解失败时，模块
返回无样本的显式降级状态；不会用系数扣减、预载数组或其他替代方式伪造
物理数值。

## 输出与审计

每个结果固定记录 SPMe、Prada2013、PyBaMM 版本、验证器版本、完整请求、
程序构造规则、终止原因和边界风险。审计配置必须逐字保存实际传入
`pybamm.Experiment` 的步骤，以及当次构造使用的上下截止电压；若依赖加载、
程序构造或求解失败，则保留已构造步骤与截止电压（如有），否则明确标记为
`not-generated` / `unavailable`，不得省略或伪造。所有状态都无条件携带：

> 参数未针对目标电芯标定，仅供短期趋势与边界核验

输出样本仅来自 PyBaMM 解的 `Time [h]`、终端电压、电流、放电容量与原生
SOC 序列。若安装版本未暴露这些必要序列，核验应失败并明确说明，而不是从
其他曲线推断或补造 SOC。

## 版本与适用范围

`physics-short-horizon-v1` 是内部模块版本。正式运行必须在已锁定并回归验证的
PyBaMM 发布版上执行，并在工具层以 `ToolResult` 记录输入哈希、数据版本、
模型版本和来源链后，才可进入面向用户的审计报告。
