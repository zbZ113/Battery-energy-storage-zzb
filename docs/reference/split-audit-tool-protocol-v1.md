# 数据集划分审计工具协议 v1

`audit_dataset_split` 审计一个已通过 `SplitManifest` 契约验证的电芯级划分。它不读取
采样点、标签或特征，也不修复、重划分或训练任何模型。

## 约束

- `SplitManifest` 在输入验证阶段拒绝同一 `cell_id` 跨训练、验证、校准、测试集合。
- 工具默认要求四个集合均非空；缺失集合会产生可审计的阻断性结果，而不会静默继续。
- 调用方必须显式声明 `split_version`、数据版本、特征版本和来源记录。

## 输出

输出的 `ToolResult` 包含：数据集、划分版本、随机种子、四个集合的电芯数量、总电芯数量、
无交叠状态、阻断状态和原因代码。集合数量是审计结果，不是寿命、SOH、RUL 或模型性能数值。

当输入本身违反电芯级不交叠契约时，注册表会拒绝该调用；当划分无交叠但缺少必需集合时，
工具返回 `blocked=true`，使下游训练、Conformal 校准和报告生成能够显式降级。
