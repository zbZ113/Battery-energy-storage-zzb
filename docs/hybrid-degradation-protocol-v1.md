# 混合退化轨迹模型协议 v1

## 目的

`hybrid-degradation-v1` 使用截至固定截断周期的真实 SOH 观测和已声明的工况特征，
预测有限预测轴上的 SOH 轨迹。它服务于公开 LFP 数据上的研究验证，不代表企业工业
大容量电芯的实测寿命结论。

## 输入与防泄漏

- 每个训练样本仅允许 `observed_cycles <= cutoff_cycle` 的 SOH 进入特征构造；最后一个
  观测周期必须正好等于截断周期。
- 训练目标 `target_cycles` 必须严格位于截断周期之后，且训练样本的电芯集合必须与
  `SplitManifest.train` 完全一致。
- 预测工况字段必须与训练时声明的字段集合完全一致；缺测、非有限、重复周期、越界
  周期和版本不一致均被拒绝，不作静默填补。
- 截断周期已经满足 `SOH <= 0.80` 的电芯不进入该外推模型。该情况必须由上游数据/决策
  工具标记为已到达 EOL 或需要人工复核，而非生成正的剩余寿命。

## 结构性单调模型

模型在归一化的真实预测周期位置 \(u_t\) 上计算：

\[
\widehat{SOH}(t)=SOH_k-D_{trend}(u_t)-\lambda\sum_{j\leq t}
\operatorname{softplus}(r_\phi(x,u_j))\Delta u_j
\]

其中趋势项由非负的平方根、线性和拐点加速项组成；残差增量经 `softplus` 约束为
非负并累计。因而每个预测点只会维持或降低 SOH，单调性不依赖在展示层截断或仅依赖
惩罚项。预测位置由 `(cycle - cutoff) / (last_prediction_cycle - cutoff)` 计算，保留非均匀
预测周期的真实间隔。

模型还加入二阶差分平滑正则，避免残差项产生不合理的锯齿。训练与推理固定随机种子
`20260712`；实现只接受内存对象，不读取 pickle、joblib、`.pt` 或 `.pth` 制品。

## EOL80 与 RUL

EOL80 不由独立模型头预测。系统仅在预测轨迹中寻找首次
`SOH <= 0.80` 的预测周期；RUL 等于该周期减去截断周期。若有限预测窗口内没有越阈，
输出没有观测到交叉，而不是虚构窗口外寿命。输出对象会重新计算并校验该交叉，拒绝
轨迹与 EOL/RUL 元数据不一致的构造。

## 适用范围与后续校正

该模型的点轨迹不是完整的不确定性结论。正式决策必须进一步通过按电芯隔离的
Conformal 校准、跨域重校准和在线个体参数校正形成可审计工具结果。模型本身不使用
PyBaMM，也不将其短期物理参考当作长期退化标签。
