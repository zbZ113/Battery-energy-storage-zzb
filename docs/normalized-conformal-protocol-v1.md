# 归一化 Conformal 区间协议 v1

## 目标

本模块为既有的 `EOL80` 点预测构造随模型难度变化的预测区间。它不训练寿命模型，
不读取原始电芯数据，也不由 LLM 生成区间端点。所有点预测和难度尺度均必须来自受控
数值工具，并在后续工具层登记输入哈希、模型版本、数据版本和来源。

## 校准输入与电芯隔离

每条校准记录由一个 `LifePrediction` 和一个正的 `difficulty_scale_cycle` 组成。尺度
必须是模型在该电芯、该截断点、该特征版本上产生的数值，并携带 `scale_version`；它
不能由真实 EOL 标签、测试集统计量或自然语言解释临时生成。

- 校准记录的电芯集合必须属于且仅属于 `SplitManifest.calibration`。
- 每个电芯恰好一条、具有真实且非右删失的 EOL80 标签。
- 数据集、截断点、目标、特征版本、划分版本、模型版本、数据版本和尺度版本必须一致。
- 训练、验证和测试电芯进入校准时立即拒绝；右删失样本不被当作观察到的 EOL。

## 方法

对校准电芯 \(i\) 计算无量纲分数：

\[
s_i=\frac{|y_i-\hat y_i|}{d_i}
\]

其中 \(d_i>0\) 为模型难度尺度。以有限样本秩
\(\lceil(n+1)(1-\alpha)\rceil\) 选取分数分位数 \(q\)。新电芯的区间为：

\[
[\max(k,\hat y-q d),\;\hat y+q d]
\]

其中 \(k\) 是预测截断周期。该构造保持点预测不变，且下界不早于截断周期。

## 评价与跨域边界

正式报告必须同时给出电芯级 PICP（实际覆盖率）和 MPIW（平均区间宽度），并按
同分布、协议留出、跨数据集和目标域重校准分别呈现。源域校准得到的目标覆盖率不自动
迁移到 HUST、Naumann 或任何未见工业域；目标域只有在独立适配电芯上重新校准后，才可
报告该域的经验覆盖率。

本模块不保证每个数据集或每种工况的覆盖率，也不能将公开实验室数据的区间解释为企业
产品质保承诺。
