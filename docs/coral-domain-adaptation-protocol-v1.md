# CORAL 跨数据集特征适配协议 v1

`coral-v1` 是“泉芯智寿”跨数据集适配链路中的无监督特征对齐基线。它用于将源域训练电芯的**早期循环特征分布**对齐至一个独立、无标签的目标域适配电芯队列；它不是寿命预测器、不会读取寿命标签，也不能代替目标域校准与 Conformal 重校准。

## 1. 适用范围与数据边界

- 源域输入必须与 `source_split_manifest.train` 的 `cell_id` 集合完全一致。
- 目标域输入必须与 `target_split_manifest.train` 的 `cell_id` 集合完全一致；该集合在跨域实验中被定义为无标签适配队列。
- `validation`、`calibration` 和 `test` 电芯均不得进入 `fit`。尤其禁止把目标域测试电芯用于协方差、均值、标准化或特征选择。
- 每行是一个电芯在既定截断点内提取的特征；特征键必须与登记的 `feature_version` 和 `feature_names` 完全一致，值必须有限。
- CORAL 不接受容量轨迹、EOL 标签、RUL、SOH 真值或任何可反推出目标寿命的字段。

这些约束由 `CORALFeatureAdapter.fit` 在运行时检查；不满足时直接拒绝，而不是静默丢弃电芯或填补数值。

## 2. 方法

设源域训练特征为 \(X_s\)，目标域无标签适配特征为 \(X_t\)。对带正则项的样本协方差 \(C_s\)、\(C_t\)，源域特征按下式变换：

\[
X_s' = (X_s - \mu_s) C_s^{-1/2} C_t^{1/2} + \mu_t.
\]

实现使用对称特征分解计算矩阵幂，并对协方差加入正的 `covariance_regularization`。这样可以在小样本、共线早期特征条件下避免奇异矩阵；若正则后仍不能得到正定且有限的协方差，适配会失败并要求复检数据或特征方案。

## 3. 输出与后续使用

输出是按 `cell_id` 返回的有限、对齐后的**源域特征**。其可被源域训练的 XGBoost 或 CPMLP/DANN 对照实验消费，但必须与下列元数据一起登记：

- `adapter_version`、`feature_version`；
- 源域与目标域 `dataset_id`、split 版本；
- 特征名、协方差正则项；
- 适配队列的精确 `cell_id` 清单及数据清单哈希。

CORAL 后的预测在目标域上仍属于跨域推断：没有独立目标域校准电芯时，不得沿用源域 90% 覆盖率声明；必须由不确定性模块执行目标域重校准或降级为“未校准”。

## 4. 不做的事情

- 不训练、加载或序列化未知模型权重；
- 不使用行级或周期级随机划分；
- 不把目标域测试集统计量泄漏到训练流程；
- 不声称公开 MATR/HUST 实验室电芯等同于济南企业或储能电站工业电芯；
- 不输出业务决策数值。批次入组、复检、降级只能由带 `ToolResult` 来源链的决策工具完成。
