# 泉芯智寿全量实施批准计划

**状态：** Approved

**日期：** 2026-07-12
**目标配置：** 最高配置、生产可审计、多智能体协同的储能电芯寿命预测与退化感知决策平台。

## 不可变原则

LLM 只编排工具和解释证据，不生成 SOH、RUL、置信区间、阈值或经营指标。所有业务数值必须来自版本化、可追溯的 `ToolResult`。数据按完整 `cell_id` 隔离；未知序列化制品不得加载；PyBaMM 仅用于短时物理核验。所有阶段都执行测试先行、哈希/版本追踪、许可证审核和明确失败降级。

## 九阶段路线

### 第一阶段：项目宪法与公共契约

落盘项目宪法、架构、数据契约、实验协议、许可证策略、第三方登记与完成定义；建立 Python 3.11 `src` 布局。实现 `EvidenceLevel`、`Decision`、`SourceKind`、`ProvenanceRecord`、`ToolResult`、`CellMetadata`、`AnalysisState` 和规范 SHA-256。门禁：核心契约单测、Ruff、mypy、compileall。

### 第二阶段：数据底座与基准快照

实现 MATR、HUST、Naumann 数据适配器、不可变原始区、标准周期模式、单位注册表、质量报告、数据卡与快照清单。按电芯生成训练/验证/测试清单，覆盖缺失、重复、协议变化、右删失与泄漏测试。产物使用 Parquet/JSON 和 SHA-256，不提交受限原始数据。

### 第三阶段：基线与统一评价

实现朴素外推、统计/生存、树模型和序列基线，预注册 SOH/RUL/校准/区间覆盖指标。随后实现 CPMLP 与混合时序模型，统一特征、截断点、删失处理和模型卡；所有指标先按电芯计算再聚合，并报告电芯级重采样区间。

### 第四阶段：可信泛化与持续学习

加入 split/group conformal、域外检测、跨 MATR/HUST/Naumann 域适应和少样本校准。设计带回放、漂移检测、候选/生产双轨及人工批准的在线更新；新观测标记 `NEWLY_OBSERVED`，失败时回退到最近已批准模型，不静默更新。

### 第五阶段：物理与机理核验

构建高斯过程退化/不确定性参考及 PyBaMM 短窗口滚动核验，检查趋势、边界和参数敏感性。模拟结果始终标记 `SIMULATED`/`PHYSICS_REFERENCE`，不得生成长期真值或混入训练标签。输出冲突证据与降级建议，而非替代数据模型。

### 第六阶段：四 Agent 与监督器

实现数据 Agent、预测 Agent、诊断 Agent、决策 Agent，以及确定性监督器状态机。Agent 只能调用注册工具并引用结果 ID；监督器负责权限、超时、重试、证据级别、冲突仲裁、`ADMIT/RECHECK/DOWNGRADE/REJECT` 与审计日志。通过故障注入和提示注入测试验证 LLM 无法绕过数值权威。

### 第七阶段：MCP 与知识库

以最小权限暴露数据目录、模型注册表、实验查询、报告渲染等 MCP 工具；构建带来源锚点、访问控制、版本与删除策略的知识库。检索文本视为不可信输入，答案逐条绑定来源；禁止知识库内容触发工具调用或覆盖系统契约。

### 第八阶段：应用、集成与交付

提供 FastAPI 契约服务、Next.js 业务门户和 Streamlit 研究工作台；支持批量与流式 BMS/EMS 接入、飞书审批/通知和可审计报告。控制类输出仅为建议，必须经过策略、授权和既有安全联锁。使用 WSL2 + Docker Compose 编排 PostgreSQL、对象存储、Redis、API 和前端，配置健康检查、备份与可观测性。

### 第九阶段：系统验证、试点与质量门禁

执行跨数据集盲测、回放、并发/性能、安全、灾备、许可证、隐私、可访问性和端到端验收。质量门禁包括 pytest、Ruff、mypy、前端 lint/typecheck/test/build、容器扫描、SBOM、制品哈希、数据/模型卡和可复现实验。先影子运行，再小流量人工审批试点；只有安全、校准、覆盖、回滚和运营指标全部达标才逐级放量。

## 阶段依赖与批准

阶段一是所有实现的契约基线；阶段二完成后方可比较模型；阶段三是阶段四和五的评价基线；阶段六只消费已验证工具；阶段七、八不得绕过监督器；阶段九批准前不得宣称生产就绪。公共契约、标签、划分、阈值或控制边界变化必须提交设计记录、迁移方案、回归证据并重新批准。
