# 顶级电芯寿命模型研究镜像设计

## 目标

在当前工程内保存顶级电芯寿命预测论文及其官方代码的完整研究镜像，支持逐文件阅读、依赖审计、复现实验和泉芯智寿 v2 模型改造。

## 边界

- GitHub官方仓库采用完整克隆，保留全部提交、分支和标签，不使用浅克隆或部分克隆。
- 论文PDF、CodeOcean/Zenodo公开制品和上游仓库放在 `research/` 下，但不进入当前主仓库Git历史。
- 主仓库只跟踪来源目录、下载器、中文导航和复现笔记。
- 不绕过登录、付费墙或访问控制；无法自动获取的官方制品记录阻塞原因和人工获取步骤。
- 不自动执行上游代码，不加载上游 pickle、joblib、`.pt`、`.pth` 或未知权重。

## 目录

```text
research/
├── upstream/       # 完整Git仓库
├── papers/         # 官方/开放获取论文PDF
├── archives/       # Zenodo和CodeOcean公开归档
├── .state/         # 本地下载状态与哈希
├── catalog.json    # 可重复来源目录
└── README.md       # 中文导航、学习顺序和项目适配建议
```

## 成功条件

1. 所有可访问官方Git仓库均为完整克隆，且可报告HEAD、分支、标签和对象完整性。
2. 所有开放获取论文均下载并通过PDF文件头与SHA-256检查。
3. DITING与BatLiNet等缺少直接代码入口的项目不会被非官方实现替代。
4. 研究镜像不会出现在主仓库 `git status` 中。
5. 任意机器可依据目录和同步脚本重新获取同一来源。
