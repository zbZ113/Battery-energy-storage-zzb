# MATR 时间精度容差与 A100 运行环境修复设计

## 一、问题与证据

三批 MATR Smoke 已完成截止循环 20 和 50 的 Dummy、Variance、XGBoost、CPMLP 与 Hybrid 任务，并在加载截止循环 100 的早期曲线时被 `NON_MONOTONIC_TIME` 阻断。

对本地三批真实 Parquet 的循环内相邻采样时间进行只读扫描后得到：

| 批次 | 负时间差数量 | 相等时间数量 | 最小时间差 | 小于 `-1e-9 s` |
|---|---:|---:|---:|---:|
| 2017-05-12 | 22 | 52 | `-2.5466e-11 s` | 0 |
| 2017-06-30 | 18 | 3 | `-2.5466e-11 s` | 0 |
| 2018-04-12 | 0 | 0 | `0 s` | 0 |

相邻记录的电压、电流和容量仍在变化，因此这些记录不是完全重复样本。负时间差比 `1e-9 s` 小两个数量级，属于浮点表示误差，不能解释为实验时间真正倒退。

首次服务器运行还确认 MLflow 3.14 默认拒绝文件型跟踪存储，必须显式设置 `MLFLOW_ALLOW_FILE_STORE=true`。服务器桌面环境会产生无关的 XRandR 错误，因此训练必须固定无头 Matplotlib 后端。

## 二、设计决策

### 1. MATR 时间单调性显式采用绝对容差

共享验证器默认保持零容差和严格单调，避免改变 Naumann 等其他数据源的契约。MATR 曲线特征通过版本化 `CurveTensorConfig` 显式使用固定绝对容差：

```text
TIME_MONOTONIC_TOLERANCE_S = 1e-9
```

- 未显式启用容差时，相等或倒退时间继续产生 `NON_MONOTONIC_TIME`。
- MATR 显式启用后，当 `current_time < previous_time - tolerance` 时，继续产生 `NON_MONOTONIC_TIME` 错误并阻断特征构造。
- 当相邻时间相等，或仅在容差范围内轻微倒退时，不修改时间、不删除记录、不改变样本顺序。
- 容差内的非严格递增产生 `TIME_WITHIN_NUMERIC_TOLERANCE` 警告，并记录电芯和循环。
- 精确重复遥测仍由现有重复遥测过滤器处理；时间容差不能替代重复样本识别。

该规则只承认数值精度误差，不放宽真实时间倒退的安全边界。

### 2. 曲线特征继续保留真实记录

放电曲线张量仍按 `sample_index` 确定循环内顺序，按电压与放电容量构造固定网格。时间字段不参与曲线插值，因此容差内时间波动不会被用于修正模型输入，也不会制造新的数值。

曲线张量应把 `TIME_WITHIN_NUMERIC_TOLERANCE` 作为非致命警告保留，使后续审计能够追踪数据质量降级。

### 3. A100 Shell 固化运行环境

训练入口固定设置：

```bash
export MLFLOW_ALLOW_FILE_STORE=true
export MPLBACKEND=Agg
export PYTHONUNBUFFERED=1
unset DISPLAY
```

- `MLFLOW_ALLOW_FILE_STORE=true` 与批准计划的本地文件型 MLflow 一致。
- `MPLBACKEND=Agg` 和 `unset DISPLAY` 防止训练依赖服务器桌面/XRandR。
- `PYTHONUNBUFFERED=1` 保证终端和 `tee` 日志实时输出。
- GPU 绑定仍由 `CUDA_VISIBLE_DEVICES=1` 控制，不改变物理 GPU 1 到 PyTorch `cuda:0` 的映射。

### 4. 恢复与制品兼容

- 不删除服务器现有 `runs/a100/matr-three-batch/smoke`。
- 修复后重新执行同一 Smoke 命令。
- 已完成且上下文哈希一致的截止循环 20、50 任务继续安全跳过。
- 截止循环 100、150 使用修复后的特征校验继续运行。
- 数据版本、划分版本、特征版本和模型配置不改变；该修复只改变错误分类的数值容差语义。

## 三、测试设计

测试先行覆盖：

1. MATR 显式启用容差时，循环内 `-2.6e-11 s` 的浮点倒退产生警告但不产生错误。
2. MATR 显式启用容差时，相邻时间相等产生警告但不阻断曲线张量。
3. 超过 `-1e-9 s` 的真实倒退继续产生 `NON_MONOTONIC_TIME` 错误。
4. 未显式启用容差时，相等时间仍作为错误拒绝。
5. 容差不能掩盖重复 `(cell_id, cycle_index, sample_index)`。
6. 曲线张量保留时间容差警告。
7. A100 训练脚本包含 MLflow 文件存储许可、无头绘图和无缓冲输出。
8. 三批真实受影响电芯在截止循环 150 均能构造曲线张量。
9. 原有数据质量、泄漏、模型与训练测试继续通过。

## 四、服务器交付

修复完成后生成仅包含代码、测试外的必要运行文件和 SHA-256 清单的小补丁，不重新传输三份原始 MAT 或已处理数据。服务器在项目根目录应用补丁后运行定向验证，再执行原 Smoke 命令恢复。

补丁不得包含 `.git`、密钥、环境文件、模型权重、检查点、原始数据或运行结果。

## 五、完成条件

- 容差内浮点时间误差不再阻断三批真实数据。
- 超出容差的真实倒退仍被拒绝。
- Smoke 可从截止循环 100 继续，并最终生成 20 份测试指标和汇总文件。
- MLflow 文件型跟踪、无头绘图和实时日志不再依赖人工临时导出。
- 已完成模型与检查点保持可复用。
