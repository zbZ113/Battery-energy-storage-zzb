# 在线个体退化参数校正协议 v1

## 1. 目的与边界

本协议定义“泉芯智寿”中**冻结全局 SOH 轨迹之后**的电芯个体化校正。它只使用已登记全局模型给出的有限预测窗口，以及该窗口内新增的真实诊断 SOH 观测；不训练、微调或替换全局模型。

本模块不承担以下职责：

- 不更新全局 ML 权重、网络结构、特征标准化器、数据划分或 Conformal 校准器；
- 不读取 `pickle`、`joblib`、`.pt`、`.pth` 或任何外部模型制品；
- 不由 LLM 生成、修改或补全 SOH 数值；
- 不对全局有限预测窗外插值或外推；
- 不将本模块输出表述为长期工业电芯实测结论。

所有测试样例均为合成数据，只证明数值服务与审计机制，不构成 MATR、HUST、Naumann 或企业数据的实验结论。

## 2. 输入契约

`FrozenGlobalTrajectory` 必须包含同一电芯的：

- `dataset_id`、`cell_id`；
- 截断循环 `cutoff_cycle`；
- 至少两个严格递增、且不早于截断点的有限 `cycles`；
- 与循环一一对应、有限且非递增的 `soh`；
- 全局模型、特征、划分与数据版本。

`NewlyObservedSOH` 只接受来源为 `NEWLY_OBSERVED` 的真实观测。每个观测必须满足：

1. `dataset_id` 与 `cell_id` 必填，且必须与 `FrozenGlobalTrajectory` **完全一致**；
2. 周期唯一；
3. 周期不早于 `cutoff_cycle`；
4. 周期处于全局轨迹的有限时间窗内；
5. SOH 有限且在 `[0, 1.5]` 内。

不满足条件的缺测、未来、重复、非有限或域外输入将直接拒绝；系统不插补、不截断、不伪造来源。

## 3. 个体参数与单调构造

全局轨迹的归一化时间为：

\[
t = \frac{c-c_{min}}{c_{max}-c_{min}}.
\]

个体校正仅优化三个有界参数：

- \(b\)：加性 SOH 偏置；
- \(r>0\)：退化速率时间扭曲倍率；
- \(k\)：中点后膝点加速偏移。

使用以下单调时间变换：

\[
t' = \mathrm{clip}\left(r t + k\max(t-0.5,0), 0, 1\right).
\]

配置要求 \(r_{min}>0\) 且 \(r_{min}+k_{min}>0\)，因此 \(t'\) 在整个预测窗中不会倒退。随后对冻结的非递增全局轨迹做线性插值：

\[
\widehat{SOH}_{ind}(t)=\mathrm{monotone\_envelope}
\left(\mathrm{clip}(SOH_{global}(t')+b,0,1.5)\right).
\]

`monotone_envelope` 采用累积最小值，作为数值级防护。因此输出从结构上保持有限、非递增；它不是只依赖一个软惩罚项的事后约束。

## 4. 目标函数与参数界限

默认界限如下，均属于版本化 `CalibrationConfig`：

| 参数 | 默认范围 | 中性先验 |
| --- | --- | --- |
| `bias_soh` | `[-0.05, 0.05]` | `0` |
| `rate_multiplier` | `[0.5, 2.0]` | `1` |
| `knee_offset_fraction` | `[-0.25, 0.25]` | `0` |

目标是带先验正则的最小二乘：

\[
\min_{b,r,k}\sum_j(\widehat{SOH}_{ind}(c_j)-SOH^{obs}_j)^2
+\lambda_b b^2+\lambda_r(r-1)^2+\lambda_k k^2.
\]

实现使用确定性的 `scipy.optimize.least_squares(method="trf")` 和固定初值 `(0,1,0)`。全局模型参数不属于优化变量，也不会传入优化器。

构造 `CalibrationConfig` 时，系统会在优化前拒绝不包含上述三个中性先验值的边界；因此不会把无效配置延迟为 SciPy 的“初始猜测超出边界”运行时错误。

## 5. 降级与复检策略

默认至少需要 3 个新增真实 SOH 点。若出现以下任一条件，返回 `RECHECK`，并保留原始全局轨迹：

- 新观测不足；
- 优化器未成功；
- 目标函数或拟合 RMSE 非有限；
- 拟合 RMSE 超过配置的 `max_fit_rmse`；
- 输入观测不满足时间窗、来源或有限性要求。

`RECHECK` 不应用拟合出的候选参数。审计记录中的 `updated_parameters` 回退为中性先验，防止不可信参数进入后续批次决策。

## 6. 审计记录与回放

每一次结果都保留：

- 冻结全局轨迹的 canonical SHA-256；
- 全局模型版本；
- 先验与最终个体参数；
- 最大已观测周期与观测数量；
- 更新版本；
- 目标函数值、拟合 RMSE、优化器状态与消息。

`replay_individual_calibration` 对 `20→50→100→150` 等给定阶段逐次执行：每一步只使用不晚于该阶段的观测，并在后续真实观测上分别报告全局轨迹和校正轨迹的 MAE/RMSE。回放**不**输出“必然提升”或“优于基线”的布尔结论；没有后续真实观测时明确标记 `NO_WITHHELD_OBSERVATIONS`。

## 7. 验收要点

- 冻结全局输入在校正前后字节语义不变；
- 输出轨迹有限且非递增；
- 重复、未来、域外、非有限和伪来源输入被拒绝；
- 低观测量和差拟合返回可审计 `RECHECK`；
- 相同输入、配置与阶段顺序下回放结果确定；
- 本模块不替代 Conformal 区间、域适应、PyBaMM 短期核验或企业级质量决策。
